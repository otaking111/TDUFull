# TDU Oʻahu Map (full version)

An interactive map of Oʻahu from **Test Drive Unlimited (2006)**, built from the game's own files.

**Open it: https://otaking111.github.io/TDUFull/**

- **Terrain:** decoded from the game's terrain textures, up to 8× detail (90112×73728) at max zoom, with lit tree crowns and ground detail from the game's own textures.
- **Animated water:** uses the game's ocean normal map and ocean settings.
- **Aircraft:** planes fly the game's own flight paths (Honolulu, Dillingham, Kalaeloa circuits).
- **521 locations:** shops, houses, 269 races/challenges (rank, group, brand, prize, medal targets, routes) and 100 missions.

Shop and house positions come from the Test Drive Wiki map, re-projected onto the game terrain. Everything else is read from the game data.
